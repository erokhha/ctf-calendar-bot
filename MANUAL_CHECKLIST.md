# Ручное завершение практики с реальными аккаунтами

Этот список дополняет уже выполненную локальную работу. Все пункты ниже требуют реального токена, аккаунтов или хостинга и в переданном пакете **не отмечены как выполненные**.

## Настройка и запуск

- [ ] В BotFather зарегистрирован отдельный учебный бот. Имя и описание отражают CTF-календарь Ерохиной; доступность username проверена в Telegram.
- [ ] В BotFather заполнены Name, About, Description, Botpic. Команды настраиваются также автоматически при старте приложения.
- [ ] Токен помещён в `.env`. Ключи OpenWeatherMap и TheCatAPI добавлены. Токены не попали в исходник/лог/скриншоты.
- [ ] В собственном личном аккаунте отправлен `/start`, затем во втором реальном аккаунте — `/start`.
- [ ] `main.py` запущен. Есть реальный снимок терминала с запуском и версии библиотек.

## Прямой Telegram Bot API

- [ ] При остановленном polling получен реальный JSON `getUpdates`; определены user ID и chat ID двух личных чатов.
- [ ] Прямым `sendMessage` отправлено приветствие; сохранён JSON `ok=true` и снимок полученного сообщения.
- [ ] Прямым `sendPhoto` отправлено изображение; сохранён JSON `ok=true` и снимок изображения в чате.
- [ ] Явной командой `broadcast ... --confirm` отправлены приветствие и изображение всем участвующим в проверке известным личным чатам. Сохранён результат обоих адресатов.

## Поведение бота с обоих аккаунтов

- [ ] `/start` приветствует конкретного пользователя; reply-клавиатура видна и уменьшена по содержимому.
- [ ] `/help` и «Помощь» показывают описание функций; неизвестная команда возвращает меню.
- [ ] `/id` / «Мой ID» показывают user ID и chat ID. У двух аккаунтов ID отличаются.
- [ ] «Мой аватар» возвращает изображение робота с фоном. Повторный запрос при неизменных данных даёт тот же аватар; другой аккаунт получает другой URL/аватар.
- [ ] «Фото котика» возвращает настоящее фото выбранной породы. Повторный запрос обращается к API заново; случайность не гарантирует различие каждой пары фотографий.
- [ ] «Погода» предлагает поделиться геолокацией. Отправленная с телефона геолокация даёт текущую погоду, после ответа возвращается меню.
- [ ] «Погода в Москве» явно подписана как выбранный запасной город. «В меню» позволяет отказаться от отправки геолокации.
- [ ] «CTF-соревнования» показывает действующие ближайшие события. Inline-кнопки переключают карточку и сохраняют корректное соответствие дат/названия/ссылки.
- [ ] Для отчёта сохранены реальные скриншоты с собственного и второго аккаунта; на них нет токенов и чужих персональных сведений сверх нужного доказательства.

## Ошибки и размещение

- [ ] В отдельной тестовой копии повторена ошибка пустого URL/недоступного API. Бот показывает понятную ошибку, процесс продолжает работать. Рабочий URL затем восстановлен.
- [ ] В `logs/bot.log` видно время, уровень, модуль, безопасный код события; секреты отсутствуют.
- [ ] На PythonAnywhere загружены исходники, установлены зависимости и заданы ключи.
- [ ] Проверены разрешённые домены и HTTP-прокси; реальная погода, котик и CTF доступны из выбранного аккаунта хостинга.
- [ ] Сохранены реальный снимок Files, консоли и работы бота после запуска на хостинге. Ограничения бесплатной консоли отражены в выводах.

Публикация кода в GitHub в этой сессии не выполнялась. Если требуется сдача ссылкой на новый репозиторий, разместите адаптацию после проверки отсутствия `.env`, логов, рабочих ID и токенов. Архивный исходный репозиторий менять для этого не требуется.
