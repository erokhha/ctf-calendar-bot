## Что сохранено

1. Предметная область: календарь CTF-соревнований CTFtime.
2. Команда `/showctf`, дополненная более короткой `/ctf`.
3. Структура `ctf_text`: имя, тип, начало, конец, место, ссылка; отдельная обработка онлайн/очного события и неизвестного места.
4. Inline-переключение карточек соревнований внутри сообщения.

## Что переписано или добавлено

| Исходник | Учебная адаптация |
| --- | --- |
| `telebot.TeleBot`, синхронные запросы | Асинхронный python-telegram-bot 22.5 и aiohttp |
| HTML scraping и фиксированный `year=2021` | CTFtime JSON API, динамические `start`, `finish`, `limit` |
| `exec` при создании кнопок | Обычные Python-объекты клавиатур |
| Индекс callback без проверки | Проверка формата, диапазона и принадлежности снимку списка пользователя |
| Новый запрос API при каждой кнопке | Навигация по сохранённому снимку списка |
| Глобальные переменные chat IDs и файлы | SQLite, только личные чаты, активность адресата |
| `tokenfile.txt` | .env через python-dotenv |
| Сырые журналы пользовательских сообщений | События/коды ошибок в console и file logging, redaction секретов |
| Timer-уведомления при импорте | Не перенесены; явная учебная рассылка отдельным CLI |
| Один файл, запуск на верхнем уровне | Несколько модулей и `if __name__ == '__main__'` |
| Только CTF | Дополнительно погода, котики, RoboHash, команды и меню |

`ctf_text` в `services.py` содержит явную ссылку на происхождение. Большая часть технической реализации переработана под требования методички; сохранение формата карточки и CTF-навигации делает связь с исходником предметной и проверяемой.

На проверенном commit отдельный `LICENSE` не найден: дерево репозитория содержит `.gitignore`, `README.md` и `ctf-games.py`. Новая лицензия на чужой исходник не объявляется. Этот файл не заменяет лицензию правообладателя.
